2.​ Implement a simple TCP client-server program.
●​ A client sends a message to the server and the server finds the length of the message received.
●​ If the length is an odd number, reverse the message and send it to the client, If the length is an even
number just send the length to the client.
●​ Repeat the same until the client sends a stop message to the server.
3.​ Implement a simple UDP client-server program.
●​ A client sends a message to the server, and the server replies back to the client.
●​ Client prints the fibonacci series if the length of the replied message is odd(eg:-If the length of message is
5 then print first 5 fibonacci numbers).
●​ Client prints the factorial if the length of the replied message is even(eg:- if length of message is 6 then
print factorial of 6).
●​ Repeat the same until the client sends an “exit” message to the server.
4.​ Implement a simple TCP client-server program with the following functionalities:
●​ The client sends two matrices to the server.
●​ The server adds the two matrices and computes the resultant matrix.
●​ The server identifies the largest element in the resultant matrix.
●​ The server should send both the resultant matrix and the largest element back to the client.
