    1. Implement a simple UDP client-server program.
    •  A client sends a message to the server.
    • Server finds the number of occurrences of a particular substring(eg:- client sends “banana” to the server, server reads a substring “na” from terminal. Server finds the occurrences of “na” as k=2).
    • The server sends a reply to the client k times, where k is the number of occurrences of a particular substring. For example, since k = 2, the replies sent to the client are: “na occurred 2 times”, “na occurred 2 times”.

    2. Implement a multi-user chat server using TCP with one server and two clients.
    • The first client sends a number to the server.
    • The server calculates the sum of the digits of the received number and sends the result to the second client.
    • The second client checks whether the number received from the server is prime or not.
    • The second client then sends a reply to the server as either “prime” or “not prime”.

6. Implement a simple TCP client-server program.
    • A client sends a message to the server and the server finds the length of the message received(without using builtin function).
    • If the length is an odd number, send an “odd” message to the client, else send an “even” message.
    • On the client side if the message received is “odd” then replace all the a’s by b’s in the message.
