    2. Implement a simple FTP client-server program.
    • A client opens a file and reads the content and sends that content as a message to the server and the server finds the length of the message received.
    • If the length is an odd number, reverse the message and write it to the file named “new_file.txt”, If the length is an even number just send the length to the new_file.
    • Repeat the same until the client sends a stop message to the server.
