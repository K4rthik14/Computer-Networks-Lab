# Exam Series Programs

A consolidated collection of computer-network lab exam question papers and
their client-server implementations.

| Series | Questions |
| --- | --- |
| [SERIES-1-BATCH-1](SERIES-1-BATCH-1) | UDP substring occurrence, TCP digit-sum/prime multi-client, UDP number pattern, TCP number reversal multi-client, UDP matrix multiplication and sort, TCP message-length parity |
| [SERIES-1-BATCH-2](SERIES-1-BATCH-2) | UDP consonant count/date-time, TCP reverse-or-length, UDP Fibonacci/factorial, TCP matrix addition/largest, UDP sort/second-largest palindrome, TCP Armstrong multi-client |
| [FTP-SERIES-2](FTP-SERIES-2) | FTP vowel count/date file, FTP reverse-or-length, FTP Fibonacci/factorial, FTP matrix addition, FTP sort/second-largest files, FTP Armstrong file |

Each question folder contains:

- `question.txt` - the problem statement.
- Descriptive `*_client.c` and `*_server.c` source files (multi-client questions
  include two client programs).
- `algorithm.txt` or `question.png` where the original material included one.
