Implement an FTP client-server program using TCP with the following
functionality:

- Client 1 sends a file name to the server.
- The server checks whether the file exists. If it exists, it opens the file,
  reads the number, and checks whether it is an Armstrong number.
- If the number is an Armstrong number, the server writes "Armstrong" to a
  file.
- If the number is not an Armstrong number, the server writes "Not Armstrong"
  to a file.
- The server sends the file name to the client, and the client opens the file
  and displays the result.
